# Reading room contract

**Unfinished source-only DRAFT — 0.3.0 unreleased.** This is not a finished product or a cleared binary release.

## Scope and authority

Library is the default reading surface over one shared Warehouse. Books/pages are reviewed projections, not partitions that own facts. Activity exposes saved captures, durable Curator jobs and pending review. No project setup is required. [DESIGN.md](../DESIGN.md) is the approved Lexicon design/token authority; old prototypes do not authorize a redesign.

## Direction

Quiet navigation, a context index and a measured 70ch reading canvas use ivory surfaces, near-black prose, oxblood interactions and explicit textual states. System sans owns controls; Georgia/local serif owns reading. Narrow windows disclose navigation rather than clipping a miniature desktop. Avoid dashboard tiles, chat transcripts, decorative physical books, remote fonts and promotional chrome.

## Workflow

Read a book/page, inspect its registered Warehouse support, or use the contextual composer. Saving local text/bounded attachments is not model execution. Selected-passage requests preserve their revision and locator. Native mixed selection is intended to register persistent read-only sources; per-job checkboxes select only the sources needed for an instruction, not an entire automatic folder upload. Earlier frozen QA reached the browser/files-only fallback. The source now includes a narrow app-owned WebKit reply bridge compatible with strict CSP. Later QA of the unchanged rebuilt local-preview app opened the real read-only native panel and verified Cancel with no new grants. Positive mixed file/folder selection, returned URLs, context chips, durable grants and revocation remain **BLOCKED by the permitted background input path**, not verified passes or a demonstrated mixed-selection product defect.

An optional managed Curator uses one explicitly configured/consented connection and model; an external MCP agent remains equally valid. Neither can approve its work. Jobs persist checkpoints and recover eligible work on reopen, but stop on Quit. Review compares Before/After, evidence and known affected dependencies. Reading-only proposals and factual changes have separate review paths; accepted facts need not create a book.

## Boundaries

Source grants enforce read-only scope, exclusions, ignore rules and revocation, not OS sandboxing or universal secret detection. Provider controls belong in Settings, not the reading canvas; downstream retention/training is not guaranteed. Preserve drafts and guard review, approval and job callbacks against stale navigation responses. Cross-book follow-up/outbox orchestration is incomplete; inspect affected reading surfaces deliberately. See [user guide](user-guide.md), [privacy](privacy-and-context.md) and [current verification limits](documentation.md).
